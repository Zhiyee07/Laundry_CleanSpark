# Laundry_CleanSpark
# C++ Laundry Management System

## 1. Project Overview

The Laundry Management System is a console-based application developed using C++ to manage laundry shop operations. 

The system aims to simplify laundry booking processes and customer record management.

This project was developed as a group assignment, where each team member was responsible for different system modules.

## 2. My Contributions
I was responsible for developing the following modules:

Update Order Status – Allows users to view and update laundry order statuses.

Member Payment – Implements membership payment processing.

Payment - Processes customer payments based on booking details and support loyalty point redemption.
